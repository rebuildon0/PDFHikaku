# PDFHikaku

## 概要
2つのPDFを並べて視覚的に差分比較するブラウザツール。オーバーレイ表示や差分ハイライトにより、図面・書類の変更点を素早く確認できる。

## ステータス
- 状態: 完成
- 最終更新: 2026-03

## 技術スタック
- 言語: JavaScript
- フレームワーク/ライブラリ: PDF.js
- 実行環境: ブラウザ（HTMLファイルを直接開く）

## 主な機能
- オーバーレイ比較モード
- 差分のみ表示モード
- パン・ズーム機能
- ページスケール調整
- 変更領域のハイライト
- 感度調整（変更検出の閾値）

## 使い方
```
index.html をブラウザで開き、2つのPDFをドロップまたは選択する
```

## ファイル構成
```
PDFHikaku/
├── index.html
├── app.js        # メインロジック
├── style.css
└── demo/         # サンプルPDF
```
